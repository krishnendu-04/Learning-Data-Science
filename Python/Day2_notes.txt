DATATYPES

    * integer - int - eg: 10,20
    * long integer - long int - eg: 12345678920
    * decimal - float - eg: 45.67
    * long decimal - double - eg: 1234567.68694590035
    * string - str (varchar,char) - eg: "hello","hi"

------------------------------------------------------------------------------------------

VARIABLES

    - used to store or assign a value
    - Egs:
            word = "hello"
            num1 = 123
            num2 = 75.90

------------------------------------------------------------------------------------------

TYPES OF PROGRAMMING LANGUAGE

    * Strictly typed programming language
        - Specify the datatype before using the variable
        - Like
            int num1;
            num1 = 4
            
            char word;
            word = "anu"
        - eg: C, Java, C++
    
    * Dynamicly typed programming language
        - Do not specify the datatype of the variable
        - Like
            num1 = 10
            name = "anu"
        - eg: Python, R, JavaScript
