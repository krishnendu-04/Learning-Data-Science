LIST COMPREHENSION

    - used to optimize adding elements into a list
    - single line opitmization of code

    - Case1
        * list of elements added into a list
            var = [print range]

    - Case2
        * list of elements added into a list based on condition
            var = [print range condition]

    - Case3
        * list of elements added into a list based on multiple condition
            var = [print condition1 condition2 range]
            var = [print1 if cond1 else print2 if cond2 else print3 if cond3 else print4 range]
